Broken Function Level Authorization
	Occurs when actions that can be used to manipulate other users resources are not restricted.
	Common for requests that perform actions of other users. They can be lateral actions or escalated actions.
	Lateral actions perform actions of users that are the same role or privilege as the attacker.
	Escalated actions perform actions of users that are of an escalated role like an admin.
	Here we're lookin for functional requests and trying to perform actions on other users accounts.

Create a user account
look for and document posssible requests that are vulnerable to BFLA
create another user account
Obtain user B's token and try to use it to perform actions on user A's resources/account.
